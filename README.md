# Virtual AI Assistant (Mini Alexa)

A Python-based Virtual AI Assistant developed as part of an AI & ML internship project.

## Features
- Personalized Greeting
- Basic Calculator
- Date and Time Display
- Random Jokes
- Motivational Quotes
- Random Facts
- Number Guessing Game
- Help Menu
- AI Activity Recommendation
- ML Perceptron Demonstration

## Technologies
- Python
- Random Module
- Datetime Module

## How to Run
1. Install Python.
2. Clone or download this repository.
3. Open the folder in VS Code.
4. Run:

```bash
python main.py
```
