
# Virtual AI Assistant (Mini Alexa)

## About
Virtual AI Assistant is a simple Python-based terminal assistant that provides interactive features such as calculations, date and time, jokes, motivational quotes, random facts, a number guessing game, AI-based activity recommendations and a simple perceptron demonstration.

## Features
- Personalized Greeting
- Basic Calculator
- Current Date
- Current Time
- Random Jokes
- Motivational Quotes
- Random Facts
- Number Guessing Game
- Help Menu
- AI Activity Recommendation
- Simple ML Perceptron Demonstration
- Graceful Exit

## Technologies Used
- Python
- Random Module
- Datetime Module

## How to Run
1. Install Python.
2. Open the project folder in VS Code.
3. Open the terminal.
4. Run:

   python main.py
